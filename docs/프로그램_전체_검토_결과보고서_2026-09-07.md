각 단계별 **소요 시간**과 **비용**을 입력하여 전체 프로세스 비용·시간을 자동으로 집계하는  
**AI Operations 운영 도구**입니다.

## 4. 핵심 기능 분석

### 4-1. 캔버스 페이지 (`/canvas`)

- React Flow 기반 인터랙티브 워크플로우 캔버스
- 우측 슬라이드인 속성 편집기 (Inspector)
- 헤더 실시간 Process Costing 메트릭 (전체 시간/비용 자동 합산)
- 단계 추가 버튼 / 저장 버튼

### 4-2. Zustand 스토어 (useCanvasStore)

| 기능 | 메서드 |
|------|--------|
| 노드 변경 | `onNodesChange` |
| 엣지 변경 | `onEdgesChange` |
| 연결 추가 | `onConnect` |
| 노드 선택 | `setSelectedNode` |
| 데이터 수정 | `updateNodeData` |
| 노드 추가 | `addNode` |
| 데이터 로드 | `loadCanvas` |
| 데이터 저장 | `saveCanvas` |

기본 샘플 데이터: 고객 문의 접수 → 견적서 작성 → 계약 체결 (총 85분, 40,000원)

### 4-3. API 라우트 (`/api/canvas`)

| 메서드 | 동작 |
|--------|------|
| GET | canvas-data.json 읽기 |
| POST | canvas-data.json에 저장 (타임스탬프 포함) |

> ⚠️ 현재 저장 방식: 로컬 파일 시스템(canvas-data.json)에 JSON 저장

## 9. 검토 결론

`AI Operations OS`는 워크플로우 프로세스 시각화 및 비용 집계라는 명확한 목적을 가진

- 로컬 파일 저장 방식 → Prisma DB 전환 필수
